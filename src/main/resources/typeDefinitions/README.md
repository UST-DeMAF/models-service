# Type Definitions

Copies of `edmm/edmmTypes.yaml` and `edmm/relationTypes.yaml` of [UST-DeMAF/demaf-type-definitions](https://github.com/UST-DeMAF/demaf-type-definitions) at tag `edmm-model-v1.4`.
When exporting a model, the models service writes the descriptions of these types and of their property definitions for every type with the same name (see `TypeSystem`).
Update the copies when the type definitions change.
